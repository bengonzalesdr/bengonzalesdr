## `ben@github ~ $ cat about.txt`

I build **websites, web applications, internal tools, and software** — usually somewhere between engineering, design, systems, and solving a real problem.

**Java is my main programming language.** Web development is where I spend a lot of my time, with **HTML, CSS, JavaScript, and PHP** making up the core of that stack. I also use **Python** for scripting and tooling, work with **C#/.NET**, and I'm working toward **Rust** as the next language I want to get genuinely comfortable with.

I like knowing what is happening underneath the UI too. That usually means Linux, terminals, networking, self-hosting, automation, and occasionally breaking something just to learn how to put it back together better.
